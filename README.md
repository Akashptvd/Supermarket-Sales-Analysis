# Supermarket-Sales-Analysis
Supermarket sales analysis and interactive dashboard built using Microsoft Excel.

## Project Overview
This project analyzes supermarket sales data using Microsoft Excel. It explores sales performance across product categories and outlet types, compares sales by item fat content, and examines the relationship between item visibility and sales.

## Tools Used
- Microsoft Excel
- Excel Tables and formulas
- PivotTables
- Charts and KPI cards
- Interactive slicers
- Descriptive statistics and correlation analysis

## Dataset
The dataset contains 8,523 records with information about item types, sales, outlet characteristics, item visibility, item fat content, and other attributes.

## Dashboard Features
- **KPI cards:** Total Sales, Average Sales, Total Records, and Average Item Visibility
- **Sales by Product Category:** Compares sales across product categories
- **Total Sales by Outlet Type:** Compares sales across outlet types
- **Low Fat vs Regular Sales:** Compares sales by item fat content across outlet types
- **Average Sales by Item Type:** Compares average sales across product types
- **Interactive slicers:** Filter the dashboard by outlet type, outlet location type, and item fat content

## Key Findings
- Total sales were approximately ₹1,201,681.49.
- Fruits and Vegetables was the highest-selling product category, followed by Snack Foods.
- Supermarket Type1 generated the highest total sales among the outlet types.
- Low Fat products generated higher total sales than Regular products in this dataset.
- The correlation between item visibility and sales was approximately -0.0013, indicating virtually no linear relationship.

## Methodology
The data was organized and cleaned in Excel. Inconsistent item fat content labels were standardized. PivotTables, formulas, descriptive statistics, and charts were used to analyze the data. An interactive dashboard was created to present the results.

## Project Files
- `Supermarket-Sales-Analysis.xlsx` — Excel workbook containing the analysis, dashboard, and supporting worksheets.

## Conclusion
This project demonstrates the use of Excel for data cleaning, exploratory analysis, statistical analysis, data visualization, and interactive dashboard development.
